title: "RunBrowser is now the browser layer for termio"

---

RunBrowser has moved. The code, the history and the design notes now live at
[termio-sh/browser](https://github.com/termio-sh/browser), and the project is becoming the
browser layer for [termio](https://termio.sh) — a terminal-first environment for coding agents.

The idea hasn't changed: give an agent **your real Chrome**, with your logins, cookies and
extensions already there, instead of a fresh headless instance that is logged into nothing.

What did change is the interface. The old CLI had 38 commands — `click`, `fill`, `snapshot`,
`@ref` element handles. They're gone. Chrome's DevTools Protocol is already complete and
documented, and models are trained on it, so a hand-written vocabulary on top only got in the
way. What's left is `cdp` and `eval`, and the reasoning is written down in
[the RFC](https://github.com/termio-sh/browser/blob/main/rfcs/minimal-cdp-surface.md).

One thing worth knowing if you came here to install it: since **Chrome 136**, the
`--remote-debugging-port` switch is ignored for your default profile, and a separate
`--user-data-dir` gets different encryption. A Chrome extension is now the only way into a
browser you're actually logged into. That's the part being built.

**Status:** mid-rewrite. The published npm package is the older version, and `main` is not
shippable yet. Watch the repo if you want to know when it is.
