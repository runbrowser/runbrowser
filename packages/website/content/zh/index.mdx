RunBrowser 搬家了。代码、历史和设计记录都在
[termio-sh/browser](https://github.com/termio-sh/browser)，这个项目正在成为
[termio](https://termio.sh) 的浏览器层——一个面向编程 agent 的终端优先开发环境。

想法没变：让 agent 用**你真实的 Chrome**，你的登录态、cookie 和扩展都在，而不是一个什么都没登录的全新无头实例。

变的是接口。旧 CLI 有 38 条命令——`click`、`fill`、`snapshot`、`@ref` 元素句柄，现在都删掉了。
Chrome DevTools Protocol 本身已经完整且有文档，模型也在上面训练过，再手写一层词汇表只会挡路。
留下的是 `cdp` 和 `eval`，理由写在
[这份 RFC](https://github.com/termio-sh/browser/blob/main/rfcs/minimal-cdp-surface.md) 里。

如果你是来安装的，有件事值得知道：从 **Chrome 136** 起，`--remote-debugging-port` 对默认 profile
不再生效，而换一个 `--user-data-dir` 会用不同的加密。也就是说，要进入一个你真正登录着的浏览器，
Chrome 扩展是现在唯一的路。这正是在做的部分。

**状态：** 重写中。npm 上已发布的是旧版本，`main` 还不能用。想知道什么时候能用，watch 一下仓库。
