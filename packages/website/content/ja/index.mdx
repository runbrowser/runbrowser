description: "RunBrowser は termio-sh/browser に移動しました。CDP で実際にログイン済みの Chrome を操作するという考えはそのまま、termio に組み込まれます。"
toc: []
---

RunBrowser は移動しました。コード、履歴、設計メモは
[termio-sh/browser](https://github.com/termio-sh/browser) にあり、このプロジェクトは
[termio](https://termio.sh)——コーディングエージェント向けのターミナル中心の開発環境——の
ブラウザレイヤーになります。

考え方は変わりません。何もログインしていない新しいヘッドレスインスタンスではなく、
ログイン情報・Cookie・拡張機能がそのまま入った**あなた自身の Chrome** をエージェントに渡します。

変わったのはインターフェースです。以前の CLI には `click`、`fill`、`snapshot`、`@ref` など
38 のコマンドがありましたが、すべて削除しました。Chrome DevTools Protocol は既に完全で
ドキュメントもあり、モデルもそれで学習しています。その上に手書きの語彙を重ねても邪魔になるだけでした。
残ったのは `cdp` と `eval` で、理由は
[RFC](https://github.com/termio-sh/browser/blob/main/rfcs/minimal-cdp-surface.md) に書いてあります。

インストール目的で来た方へ。**Chrome 136** 以降、`--remote-debugging-port` は既定のプロファイルでは
無視され、別の `--user-data-dir` は暗号化が異なります。実際にログイン済みのブラウザに入る手段は、
現状 Chrome 拡張だけです。今作っているのはその部分です。

**状況:** 書き直し中。npm で公開されているのは旧バージョンで、`main` はまだ動きません。
