title: "RunBrowser est désormais la couche navigateur de termio"
description: "RunBrowser a déménagé vers termio-sh/browser. Même idée — piloter votre vrai Chrome connecté via CDP — désormais intégrée à termio."
toc: []
---

RunBrowser a déménagé. Le code, l'historique et les notes de conception se trouvent
maintenant sur [termio-sh/browser](https://github.com/termio-sh/browser), et le projet devient
la couche navigateur de [termio](https://termio.sh), un environnement orienté terminal pour les
agents de code.

L'idée n'a pas changé : donner à un agent **votre vrai Chrome**, avec vos sessions, vos cookies
et vos extensions déjà en place, plutôt qu'une instance headless connectée à rien.

Ce qui a changé, c'est l'interface. L'ancienne CLI comptait 38 commandes — `click`, `fill`,
`snapshot`, les handles `@ref`. Elles ont disparu. Le protocole DevTools de Chrome est déjà
complet et documenté, et les modèles sont entraînés dessus : un vocabulaire écrit à la main
par-dessus ne faisait que gêner. Il reste `cdp` et `eval`, et le raisonnement est consigné dans
[la RFC](https://github.com/termio-sh/browser/blob/main/rfcs/minimal-cdp-surface.md).

À savoir si vous venez pour l'installer : depuis **Chrome 136**, l'option
`--remote-debugging-port` est ignorée pour le profil par défaut, et un `--user-data-dir` distinct
utilise un chiffrement différent. Une extension Chrome est désormais le seul moyen d'atteindre un
navigateur réellement connecté. C'est cette partie qui est en cours de construction.

**État :** réécriture en cours. Le paquet npm publié correspond à l'ancienne version et `main`
n'est pas encore utilisable.
